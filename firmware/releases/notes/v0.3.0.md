# FrogAlert 0.3.0

Stable release at the owner's request following successful hardware use of the
Rust application. This release focuses on unexpected wake and power handling.

- Correct the PB22 wake interrupt mux, which previously selected floating LED
  pin PB8; arm only the exact-profile buttons and clear stale interrupt state.
- Qualify wake presses/releases in Rust and preserve off intent across resets.
  Keep KEY2's continuous roughly 2.2-second ROM-ISP recovery hold.
- Enter full hardware shutdown after radio idle. If the controller cannot
  acknowledge shutdown within 30 seconds, reset into a marked-off boot instead
  of remaining dark and draining the battery indefinitely.
- Detach USB/DMA before shutdown and power down the ADC between readings.
- Replace the default animated FOSSASIA welcome with a 500 ms static credit
  and 500 ms battery card; preserve custom splashes and manufacturer attribution.
- Add actual shutdown-adapter register fault tests, wake debounce/ISP tests,
  and radio reset-deadline tests for both profiles and views.
- Desktop Linux WebUSB access denial now shows device-specific udev rules with
  a copy button; Android and other operating systems receive suitable guidance.

The application remains allocation-free Rust on the proven FOSSASIA/WCH C
hardware shell. New images are CI-audited; exact-image current consumption,
spontaneous-wake elimination, and recovery still need physical confirmation.
Stable labeling does not assert those measurements were performed.

See [the power audit](https://github.com/pierce403/frogalert/blob/main/docs/POWER_AUDIT.md).
