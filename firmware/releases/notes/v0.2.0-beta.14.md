# FrogAlert 0.2.0-beta.14

This release restores Android BadgeMagic name-upload compatibility by
withdrawing beta.12's hardware-shutdown experiment. The owner reported that
the same Android app and badge could upload a new name on beta.11 but not on
beta.12. The legacy `FEE0` service, `FEE1` write characteristic, and packet
parser were unchanged between those releases; the only firmware runtime change
was the new shutdown and early-wake integration.

Beta.14 restores beta.11's recoverable application screen off. The physical
top button cycles normal → Bluetooth download → screen off → normal. While
dark, the firmware disables advertising and passive discovery, stops display
refresh, and releases the LED matrix, but keeps the button, TMOS, USB, and
unchanged KEY2 recovery tasks alive.

This deliberately gives up beta.12's lower-power hardware shutdown until a new
design passes BadgeMagic upload, screen-off current, wake, and KEY2 recovery
tests on both exact PCB profiles. The beta.14 pair remains CI-audited and
hardware-unverified until the fix is confirmed on a physical badge.
