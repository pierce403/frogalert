# FrogAlert 0.2.0-beta.12

This release changes screen off from an application-only dark state to the
CH582 hardware shutdown path used by the standard FOSSASIA firmware. Passive
discovery is cancelled and confirmed idle before shutdown, so BLE, USB, TMOS,
both application timers, and matrix drive are no longer kept running while dark.

Wake remains bound to the exact board profile. `B1144C_260404` wakes from its
physical-top KEY2 button; `B1144C_250901` wakes from physical-top KEY1 and also
arms KEY2 so a continuously held recovery press can still enter mask-ROM ISP.
A marked shutdown wake cold-boots the application. KEY2 is qualified at the
inherited 200 ms cadence before USB or display startup, and the `250901` image
returns to shutdown after a sub-threshold KEY2 recovery press.

The detector chart also groups both Meta-glasses hints together above the
Axon/TASER name hints while keeping frog dance at the highest priority.

The two exact counter images are built, audited, and published by the canonical
GitHub Actions workflow. The homepage downloads and guided flasher resolve the
same atomic release pair from the same-origin manifest.

This release is source- and CI-audited, not hardware-tested. Keep
`hardware_verified: false` until both exact images pass current measurement,
top-button off/wake without USB, charge wake, repeated cycles, BadgeMagic
upload, and a continuous KEY2-from-dark ISP test.
