# FrogAlert 0.1.0-beta.1

The first public FrogAlert beta keeps the normal BadgeMagic nametag and upload
path while adding passive Bluetooth surveys, a fixed Bluetooth counter, and
temporary fixed-page alerts.

Two exact images are included:

- the top-button image for PCB marking `B1144C_260404`;
- the bottom-button image for PCB marking `B1144C_250901`.

Use the `/flash/` wizard and follow the button path it observes. The site
downloads the matching image from the same origin, checks its size, SHA-256,
embedded profile, and quarantine status, then programs and verifies every
chunk.

This is beta firmware based on user-confirmed physical operation. Exact-hash
CLI and WebUSB program/verify transcripts were not captured before publication
and remain required for a stable release. The original read-protected OEM image
cannot be backed up or restored.
