# FrogAlert 0.2.0-beta.2

This release adds passive Flipper Zero detection from the advertised 16-bit
serial-profile services `0x3081`, `0x3082`, and `0x3083`, matching the signal
used by BLESPloit. The existing case-insensitive `Flipper` name rule remains as
an independent fallback. No connection, active probe, or hardware change is
required.

It also introduces automatic publication of the standard counter pair after
the canonical GitHub Actions build, linked-image audits, quarantine check,
candidate receipt validation, and provenance attestations pass. Both exact
USB-C profiles become available from the phone flasher together.

The phone flasher now prepares and verifies both profile images before ISP
entry. As soon as the WCH bootloader is claimed it runs the read-only
`wchisp info` equivalent, then asks whether the top or bottom button entered
ISP. That explicitly destructive answer binds the matching image and starts
configuration reset, programming, and byte verification immediately.

These exact binaries are CI-audited but were not physically smoke-tested before
publication. The site displays that status and still requires the exact PCB
profile, irreversible-OEM warning, stable power confirmation, programming, and
byte verification.
