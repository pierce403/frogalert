# FrogAlert 0.2.0-beta.16

This release fixes a delayed spontaneous screen-on observed after hardware
shutdown. The inherited FOSSASIA power path armed the active-low charger-status
output on PA0 as a falling-edge wake source. A charger-state transition or
electrical glitch could therefore wake the CH582 long after the user turned
the badge off, and FrogAlert previously accepted that reset as permission to
boot normally.

FrogAlert screen off now enables only the exact-profile top/system button and
the KEY2 recovery input. Charger status remains readable during normal
operation but cannot wake shutdown. Early boot also fails closed: if no valid
button remains asserted, the badge immediately returns to shutdown instead of
lighting the matrix.

The beta.15 low-power and BadgeMagic transfer hardening remains unchanged.
These changes are source- and CI-audited, not physical proof; both exact PCB
profiles still require prolonged plugged and unplugged screen-off tests,
explicit wake, KEY2 recovery, current measurement, and Android uploads.
